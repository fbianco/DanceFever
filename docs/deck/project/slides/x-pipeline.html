THE PIPELINE

From a frame to a score, 30 times a second

Two convolutional networks (Google MediaPipe, run in the browser with WebAssembly and WebGL) turn each frame into 33 points; the game turns the points into a score.

Parts 1 → 2: photo = the array I ∈ [0,1]^(H×W×3) · find you = detector + alignment · stickers = landmark regression · stick figure and arrows = unit vectors and cosines.

This is the map for the rest of part 2. A camera frame of 960 by 540 RGB pixels arrives about 30 times a second. A first network, the detector, looks at the whole frame shrunk to 224 by 224 and outputs candidate boxes. From the best one it derives an alignment: a centre, a size and a tilt. That defines an affine crop, rotated so the person stands upright, resampled to 256 by 256. The second network, the landmark network, outputs 39 points with 5 numbers each. The game then turns these into 9 bone directions and compares them with the coach to get a score in [0,1]. The dashed loop is important for speed: in video mode the crop for the next frame is predicted from the current points, so the detector only runs when tracking is lost.
