Body tracking: Google MediaPipe Pose Landmarker lite (Apache-2.0) · V. Bazarevsky et al., “BlazePose: On-device Real-time Body Pose tracking”, 2020 · Dance Fever by Bianco’s Labs

Here is the whole chain in one line. Pixels go into a detector that finds the dancer and an alignment; the aligned crop goes into the landmark network, which gives 33 points with a visibility; the game smooths them, turns them into nine directions, compares them with the coach using cosines, and turns the best match around each beat into PERFECT, GOOD, OK or MISS. For the children: photo, find you, stickers, stick figure, arrows. To try it, double-click start.bat in the DanceFever folder, allow the camera and raise both hands. Without a webcam, the demo address shows two automatic dancers. The automated tests can be run with npm test.
