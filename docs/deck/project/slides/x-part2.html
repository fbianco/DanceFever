PART 2

The same pipeline, with the mathematics and the physics

For mathematicians and physicists. Every network figure comes from the model file the game ships (pose_landmarker_lite.task); every game figure from its source code.

Part 2 retells the story of part 1, step by step, for an audience comfortable with linear algebra, calculus and a bit of optics. Photo becomes an array I in [0,1]^(H×W×3); “find you” becomes an anchor-based detector with an alignment transform; “stickers” becomes a convolutional regression network; “stick figure” and “arrows” become unit vectors on a torus and cosine similarities. The network figures (input sizes, layer counts, weights, multiply-adds, output tensors) were read directly from the two TFLite models inside pose_landmarker_lite.task, not quoted from memory.
