STEP 2 · THE STICKERS

Inside both networks: stacked convolutions

One convolution layer

y[x,y,k] = b_k + Σ_c Σ_(i,j) K[i,j,c,k] · I[x+i, y+j, c]

The same small kernel K slides over the whole image (translation equivariance), followed by a pointwise nonlinearity. Early layers respond to edges, later ones to limbs.

Depthwise separable: the cheap version

full k×k: k²·C·C′ per pixel

depthwise k×k + 1×1: k²·C + C·C′

ratio = 1/C′ + 1/k² ≈ 1/9 (k = 3)

The landmark network is an encoder–decoder: resolution goes down, then back up (5 bilinear upsamplings, 25 residual additions) to 64 × 64 heatmaps.

Both networks are stacks of convolutions. A convolution layer computes, for each output channel k and position (x, y), a weighted sum of a small k by k neighbourhood over all input channels, plus a bias, then a nonlinearity. The same weights are used at every position, which is why a network can find an elbow wherever it is in the crop. To save computation, MobileNet-style networks split a full convolution into a depthwise k by k filter per channel and a 1 by 1 pointwise mixing: the cost ratio is 1 over C prime plus 1 over k squared, roughly one ninth for 3 by 3 kernels. The table on the right is not from a paper: it was measured from the model file. The detector has about 3 million weights in dense form, but roughly 70 percent are zero and stored sparsely. The landmark network has 1.36 million weights and needs about 0.2 billion multiply-adds per run, which is why it runs in real time in a browser.
